# ChatGPT App for iOS 14

A standalone, Gecko-powered ChatGPT app designed for jailbroken iOS 14 devices, based on [Reynard Browser](https://github.com/minh-ton/reynard-browser).

## Changes in v1.31

- Updated to Reynard 0.22.1 and Gecko 160.0.
- Adapted for iOS 14 and rootful jailbreaks.
- Improved header and button rendering.
- Retained custom gestures, full-screen interface, microphone support and conversation restoration.
- Available as standalone IPAs for TrollStore and jailbroken devices.

## Download

[Download the latest IPA from Releases](https://github.com/551UK/ChatGPT-App-iOS14/releases). Install only one variant. Device compatibility is still being tested.
